## M2 缓存体系

- [x] Redis 工具框架与 Key 治理：RedisCache 封装（String/Hash/Set/ZSet）+ KeyManage/KeyBuild 前缀规范 —— 2026-08-28~09-02（M2.1~M2.2）
- [x] 缓存三防：旁路缓存 + 穿透空值缓存 + 雪崩 TTL 抖动 + 击穿互斥锁/逻辑过期双方案（A/B 实测） —— 2026-09-02~09-03（M2.3~M2.7）

## M3 秒杀核心链路

- [x] 纯 DB 下单与超卖实录：秒杀 V1 + JMeter 压测暴露超卖 + 乐观锁修复（基线 QPS 88.8/s） —— 2026-09-11~09-16（M3.1~M3.2）
- [x] 分布式锁与一人一单：Redisson 四种锁 + @ServiceLock AOP + 唯一索引兜底三层防线（10 单→1 单） —— 2026-09-16（M3.3~M3.5）
- [x] Redis+Lua+Kafka 异步秒杀：库存预热 Lua 原子扣减 + MQ 框架（acks=all/幂等生产者）+ 异步建单（QPS 74.9→168、峰值吸收 847/s、Avg -81%） —— 2026-09-16（M3.6~M3.8）
- [x] 一致性闭环：缓存失效广播 + @RepeatExecuteLimit 三级幂等 + 消费可靠性（退避/耗尽回滚/超龄丢弃）+ 对账日志（traceId 三层串联） —— 2026-09-16~09-22（M3.9~M3.12）
- [x] 流量防线：限流原语（令牌桶/滑动窗口 Lua，50 并发零超发）+ 场景化限流（@RateLimit 双维度独立配额/白名单/封禁/fail-open）+ 秒杀前置令牌（限流闸门+一次性消费） —— 2026-09-22（M3.13~M3.15）

## M4 数据层扩展

- [x] 全局 ID：自研雪花（时钟回拨分档：小回拨等待/大回拨拒绝，时间源注入可测）+ Redis Lua 轮转分配机器位 —— 2026-09-22（M4.1~M4.2）
- [x] 双库分片：分片设计（`docs/sharding.md`）+ ShardingSphere 5.5.1 编程式接入（库 user_id%/表 voucher_id%，非分片表 SINGLE 落 ds_0）+ 订单路由表反查 + 订单 ID 切自研雪花 —— 2026-09-22（M4.3~M4.5）

## M5 一致性与运营闭环

- [x] **M5-A 对账体系**：定时比对（Redis 流水 vs DB，宽限期只护差异判定）+ PENDING 翻牌 + 差异补偿（复用统一回滚，orderId 以 traceId 顶替）+ 失败表"删旧走新"重试收敛 + 行龄告警 —— 2026-09-22
- [x] **M5-B 延迟队列与订单超时关单**：delay-starter（RDelayedQueue 分片/线程池消费/失败重投×3/耗尽告警）+ 关单闭环（条件关单幂等闸门→DB 逆增量→复用统一回滚退资格）+ 对账"终态流水未恢复"裁决联动 —— 2026-09-23
- [x] **M5-C 通知与运营统计**：预通知（活动级延迟任务"闹钟挂活动上响时查名单"+等级圈人+Top 附加+SETNX 防重+收件箱）+ 订阅闭环（ZSet 排队/Hash 状态/回流 popMin 自动发券复用异步建单）+ 店铺每日 Top 买家（ZINCRBY 按日 key）—— 2026-09-23
