# Localink 演示剧本（10 分钟一条龙）

> 用途：面试演示 / 联调自测走查。前置：`powershell -File scripts\dev-all.ps1 -DevSms`（一键起前后端 + 自动取码）。
> 每步含 **操作 → 预期 → 机制一句话**；机制句即面试叙事锚点，讲的时候点一句即可，别展开（展开的内容在 docs/interview-qa-30.md）。

## 准备（1 分钟）

- 起服务：`powershell -File scripts\dev-all.ps1 -DevSms`，看到双端 [OK] 后打开 `http://localhost:5173/`。
- 若需演示秒杀/订单监控，先用 `/admin → 券与活动` 给商户 1 建一场"进行中"的秒杀活动（支付价 5 元、面值 50 元、库存 10、时间窗含当前时刻）。

## C 端主线（4 分钟）

1. **登录**：社区页右上"登录"→ 输手机号 → 发送验证码（dev 模式自动回填）→ 登录。
   机制：验证码存 Redis 120s 一次性；token 裸值放 Authorization，30 分钟滑动续期。

2. **商户列表 → 详情**：首页看商户（53 家种子+自建），点进一家，看缓存命中的详情字段。
   机制：读路径四级纵深——Caffeine 本地 → 布隆 → Redis 逻辑过期 → DB；改商户后看更新即时生效（写后失效+广播+延迟双删）。

3. **领普通券**：详情页"立即领取"→ toast 返回订单号。
   机制：普通券即领即得（无库存概念），订单落分片表（库 user_id%、表 voucher_id%）。

4. **秒杀两步流**：详情页秒杀区点进活动 → "第一步：申请令牌"（30s 倒计时可见）→ "第二步：立即抢购" → 成功跳"我的订单"。
   机制：令牌把瞬时洪峰拆成两段可分别限流的请求；真正扣减是 Redis Lua 原子"判库存+判重+扣减+流水"，Kafka 异步建单（返回订单号时订单可能尚未落库，刷新即可见）。

5. **重复抢购被拒**：回秒杀页再走一遍两步流 → toast"每人限购一单"。
   机制：一人一单在 Lua 内判重 + DB 唯一索引兜底（active_flag 生成列）。

## 运营后台（3 分钟）

6. **后台管理**：`/admin`（导航直接输地址）→ 登录 → 商户管理（可现场新建一家，回 C 端列表立即可见——演示缓存失效链）→ 券与活动。
   机制：admin-guard 演示单机默认关（对外部署必须开+白名单，见 deploy.md）。

7. **订单监控 → 模拟超时关单**：选商户 1 与刚才的活动 → 看到订单（券名回填）→ 点"模拟超时关单" → 状态变"超时关闭"。
   机制：正路是 15 分钟延迟队列自动关单；手动按钮是同一套幂等关单（条件 UPDATE 仅 status=1）——关单同时回补库存、回滚 Redis 资格、订阅者自动回流发券。

8. **订阅提醒 + 对账看板**：订阅页看统计数字；对账页看流水行（待处理/一致）。
   机制：对账是 Redis 流水 → DB 单向比对（宽限期 2 分钟只护差异判定），差异补偿复用统一回滚；回滚失败落表周期重试。

## 社区（3 分钟）

9. **签到 + 发帖**：社区页签到卡片（连续天数）→ "发布帖子"（可带图上传）→ Feed 顶部出现。
   机制：签到是 BitMap 按月位图（一人一月 4 字节）；发帖走两级审核——显性词同步拒（30001），其余先发后审。

10. **帖子互动**：点进帖子 → 点赞（红心+计数）→ 评论 → 楼中楼回复 → 关注作者 → 共同关注弹窗。
    机制：点赞事实表+同事务冗余计数+afterCommit 进 ZSet 榜；共同关注是 Redis Set SINTER；Feed 是推拉结合（大 V 读时拉）。

11. **审核驳回演示**（可选彩蛋）：再发一帖内容带"稳赚不赔"→ 发送成功 → 几秒后刷新 Feed/搜索都找不到（详情 404）。
    机制：隐性风险词走 MQ 异步复审秒级驳回，驳回即从 DB 状态位+点赞榜+热榜+ES 全端消失——"DB 事实源+派生视图可重建"。

12. **搜索高亮**：搜索页搜刚发帖的关键词 → 标题/正文 `<em>` 高亮、左侧商户分面（聚合全集不受筛选影响）、切"按时间"排序立即生效。
    机制：IK 分词索引/查询不对称、must 算分 vs post_filter 不算分保聚合、search_after 深分页。

## 收尾

- 停服务：dev-all 窗口 Ctrl+C（自动清理双端）。
- 数据清扫：演示数据建议当场清（订单/活动按物理表，见各任务卡清扫记录）。
- 讲不出的问题别硬讲——回一句"这个细节在任务卡/文档里有记录，我可以会后翻给你"，诚实比编强。

## 演示红线（对照面试速成口径）

- QPS 数字只报实测口径（缓存命中 12310 / 拒绝 5333 / 成功路径 800 并发零超卖），不说"2000+"。
- "有反例的调优才可信"：threads.max=400 负优化回退的故事比数字加分。
- 部署口径：admin-guard 与 dev 取码开关的默认关闭是演示单机口径，生产必须开/关到位（deploy.md §9）。
